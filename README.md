## v0.6.12 玩法优化与调优（2026-10-12）

游戏标题统一为「塔羅斯监狱」，移除经营模式的资料校准标签。新增象牙、猎物、划痕、鼠巢专项练习与探查；特殊牢房采用金色事件徽章，开门后可接受或略过连锁反应、处刑效率，左侧保留效果说明，使用完成后置灰。绮彩收容头像增加七彩边框，目标、刑具和房间效果纵向分开。

新建入口只保留经营规则演习和原创押运挑战，已有存档继续或导入时保持原规则。未补齐的卡池、事件权重和操作成本仍明确标为练习参数；经营交接之后的战斗和真实收益不在此模拟器内。作者声明第一层、永久免费提示、现行分享海报和存档导入导出保留。

发布准备完成278项测试；独立检验覆盖50局和334次存档导入/重放，96个公开运行文件依赖完整。桌面入口与标题已实际核对；手机实机仍待补验。


## v0.6.13 电脑性能与浏览器兼容（2026-10-12）

电脑场景的悬停只刷新高亮，房间投影和阴影在实际需要时更新；返回起始页、查看菜单或切到后台时暂停场景绘制，返回后继续。高分辨率电脑按像素面积控制渲染缓冲，保持相机、16间牢房和点击区域。手机画质和装饰动画设置保持原样，本轮不做移动端专项优化。

经营记录采用前缀追加重放和不可修改的派生视图，同一条记录重复悬停不重建浮层；撤回、导入与记录修改会重新验证。补齐旧浏览器条件赋值语法及房间列表DOM接口降级，首页兼容旧式屏幕监听，无WebGL时停止空转。游戏规则、存档和声音资源没有调整。

电脑本机纯计算样本中，正常20日记录的重复详情约9.29ms降至0.069ms；512条记录压力样本约314.33ms降至0.198ms。此为Node计算耗时，不是GPU帧率或用户设备测量。真实浏览器继续验证菜单暂停/恢复、开门与选择，全套验收记录另行保留。
